# Madhav Sales Dashboard (Power BI)

## 📌 Project Overview
This project is an interactive **Sales Dashboard** created in **Power BI** to analyze sales performance, profit trends, customer purchasing behavior, and regional sales distribution for Madhav Store.

The dashboard helps stakeholders make data-driven decisions by tracking key business metrics and identifying profitable categories, cities, and payment methods.

---

## 📊 Dashboard Features

### KPI Cards
- Total Sales Amount: **438K**
- Total Profit: **37K**
- Total Quantity Sold: **6K**
- Average Sales Value: **121K**

### Visual Insights
- **Profit by Sub-Category**  
  Identifies most profitable products like Printers, Bookcases, Saree, Accessories, and Tables.

- **Profit by Month**  
  Monthly profit trend showing peak and low-performing months.

- **Top 4 Cities Sales**  
  Highest sales generated from:
  - Indore
  - Mumbai
  - Pune
  - Mathura

- **Quantity by Payment Mode**  
  Customer preferred payment methods:
  - COD
  - UPI
  - Debit Card
  - Credit Card
  - EMI

- **Quantity by Category**  
  Sales contribution by:
  - Clothing
  - Electronics
  - Furniture

### Filters Included
- Quarterly Filter (Qtr1, Qtr2, Qtr3, Qtr4)
- Category Dropdown Filter

## 📈 Key Insights
- Clothing category contributes the highest quantity sold (**62.62%**)
- COD is the most used payment mode (**43.74%**)
- November generated highest monthly profit
- Indore is the top-performing city in sales
- Printers generated highest profit among sub-categories
